# Public-benchmark artifacts

This directory contains the public-benchmark material recovered from the frozen local handoff.

- `biodex/` contains the TADA, DocETL, and direct-model manifests, predictions, summaries, and experiment scripts available in the handoff. Large embedding caches and superseded partial-run summaries are omitted.
- `cuad/` contains the recovered CUAD extraction implementation, repetition launcher, and smoke evidence. The handoff did not contain the final three full CUAD prediction files, so this directory should not be interpreted as a complete raw-output reproduction package.

Any local endpoints and absolute workstation paths were removed or replaced with environment variables during release preparation.
