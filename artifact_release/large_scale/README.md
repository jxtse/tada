# Large-scale execution artifacts

This directory contains the recovered artifacts for the final large-scale end-to-end experiments:

- `rq3_e2e_results.csv` and `.md`: publication aggregate table;
- `runs/`: three TADA-Agent and three Claude Code run records for each reported workload;
- `gold/`: reference taxonomies, labels, and voted-label files used by the scoring scripts;
- scoring and table-building scripts.

The local handoff did not contain the later six-population candidate-retention trial bundle described in the supplementary material (population CSVs, 480,000 trial records, and planner diagnostics). Those files are therefore not claimed as part of this public release.
